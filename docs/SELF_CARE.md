# 體力、飽足、脾氣與休息

每局起始為體力88、飽足70、脾氣18，三項皆限制在0～100。規則由 `game/vitals.js` 共用，底部「狀態規則」可隨時查閱。

| 行為 | 體力 | 飽足 | 脾氣 |
| --- | ---: | ---: | ---: |
| 完成一件工作（含兩件早晨病房工作） | -6 | -5 | -4 |
| 一般來電 | 0 | 0 | +8 |
| 緊急來電 | 0 | 0 | +12 |
| 錯誤選項一次 | 0 | 0 | +8 |
| 跨棟／搭電梯 | -1 | 0 | +1 |
| 走動，每秒 | -0.12 | -0.04 | 0 |
| 站著，每秒 | -0.03 | -0.04 | 0 |
| 坐下，每秒 | +1.5 | -0.04 | -0.4 |
| 躺下，每秒 | +3 | -0.04 | -0.8 |
| 餅乾，遊戲5分鐘 | +8 | +25 | -5 |
| 飲料，遊戲3分鐘 | +6 | +10 | -4 |
| 值班餐，遊戲10分鐘 | +12 | +45 | -12 |

閱讀題目、規則及暫停時停止消耗；坐著接電話仍恢復體力。自由探索不自然扣除體力／飽足，但可以休息、補給或用規則內的按鈕試玩三種臨界事件。彩蛋每處一次緩和5～6脾氣，刀房操作請學長接手可緩和5。

## 場景與姿勢

2G工作桌加寬、加深，電腦、電話單、印表機分開互動；零食櫃位於電腦旁。電腦只顯示「電腦」。診間電腦椅可坐下等call、接電話並持續恢復體力。臨床工作或移動前會站起來；體力過低時保留坐姿等恢復。

13／16房電腦前均有可坐的椅子。刀房走廊、連通區、急診、護理站另有就近休息的椅子，避免體力不足時無處恢復。7F值班室休息會定位到實際床墊，以原主角圖像呈現躺姿、呼吸與Z字睡眠效果；午夜第一次躺下仍保留原來10秒後被電話叫起的劇情。

坐姿使用該名主角與該場景服裝的原有插圖上半身，搭配彎曲腿部；躺姿使用原圖像平躺在床墊。姿勢切換有短暫過渡，站起來回到休息前的可行走位置，避免卡在桌子或床墊的碰撞範圍。

## 強制恢復與爆炸

- 體力 ≤10：必須就近坐下／躺下，回到30才可起身工作；保留電話與工作，坐著仍能接call。
- 飽足 =0：必須先進食，回到25解除限制。可去零食櫃／護理站，也可使用口袋備用餅乾，避免在遠處發生無法補給的死路。
- 脾氣 =100：跨門檻先記錄待發作；等回到可走動的安全畫面，顯示3秒的漫畫爆炸、角色震動及頭頂怒氣特效。之後脾氣65、體力-8、遊戲時間+3分鐘，不清掉事件進度。

## 結算

總分 = 任務原始得分／任務滿分 ×70 ＋ 體力／10 ＋ 飽足／10 ＋ (100−脾氣)／10，顯示到小數1位，限制0～100分。

結算畫面及下載值班小卡採同一公式；任務明細仍顯示各件10分、選錯一次扣2分的原始分數。三個狀態的剩餘值與各自貢獻分數會列出，重複吃飯或休息不會額外堆疊超過30分。

## 驗證

`check-vitals.mjs` 驗證雙重臨界值、恢復門檻鎖定、進食、坐著接電話、暫停、不同更新頻率一致、事件中達100後延遲爆炸且只發作一次、食物與工作成本、各項分數上下界及200組狀態分數。

瀏覽器驗證：初診間坐下後體力持續上升；坐著試接主治電話，關閉後仍保持坐姿，體力由87恢復到100。臨界體力10時起身鎖住，恢復30後解除；飽足0以餅乾補到25後解除工作限制；脾氣100顯示爆炸效果並收尾到65。已試玩值班室躺姿、女主角姿勢與13房綠色刷手服坐姿。手機812×375的休息控制、零食選項與分數試算無橫向溢出，瀏覽器未出現錯誤或警告。
