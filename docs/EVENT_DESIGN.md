# 28 個事件與場景彩蛋（v0.5）

2026-10-23。科內娛樂事件草案，沿用虛構角色與醫院動線。醫療情境簡化呈現現況確認、團隊合作與交接；細部臨床選項仍由使用者逐一校閱。

## 抽選與計分

- 個人玩家每局 10～15 件，不重複；重新開始產生新場次。
- 三組同場代碼各選 A／B／C，每組 12 件：2 緊急、5 門診與一般工作、2 特殊、3 科內日常。每件 10 分，選錯扣 2 分、最低 0 分，求助與保留來電不扣分。
- 共同流程包含查房、清鼻子、08:30 門診工作與 13:30 刀房；同場三組分別抽到三種不同門診工作，其餘八件依類別平衡抽選。允許組間重疊，並非全池必定出現。
- 同碼同組可重現題組。成績在本機結算，沒有連線排行榜。
- 交接與休息為轉場。彩蛋與改密碼不占抽題、不得分，也不因找錯卡紙處、選錯分機或重複密碼扣事件分。

## 一天的流程

07:30 到護理站列印 patient list，依三床名單自行查房。房號與床號都要對上；完成整份名單後，才能回 SMP 術後病人床邊帶往檢查室清鼻子。查房與清鼻子進度跨來電、樓層保留。

08:30 由診間護理師通知「樓下門診」有殘冊、換氣切管或換鼻胃管。這是門診工作。13:30 再由13房流動轉達學長請上樓幫忙 NPX biopsy。接到通知後主流程進入 2G，第一件完成後繼續上午診間生活，不強制回病房。未完成的病房待辦保留，交班前收尾。門診三項仍依抽題出現，可在一般工作抽選中再次遇到其他門診項目；不保證每局三項全做。一般會診可在上午出現；病房「NG 放不進去」及資訊不全來電，須先回 2G 工作桌坐下才收到電話。緊急與特殊情境留在夜間，細部選項可繼續討論。

## 可隨時走近的彩蛋

| 物件 | 位置 | 互動 | 完成效果 |
|---|---|---|---|
| 印表機 | 7F 護理站、2G 初診間 | 打開紙匣、後蓋、出紙口，找到皺紙再取出 | 脾氣 −5 |
| 漏水 | 7F 冷氣、13／16 房天花板 | 電話按鍵輸入 3000，接通後說明位置與漏水狀況 | 脾氣 −6 |
| 衛生紙 | 2G 洗手台 | 打開木櫃拿一包，開紙盒補入，再抽一張確認 | 脾氣 −5 |

彩蛋不會主動彈出、不加入來電或待辦；每處每局只降低一次脾氣，跨樓保留開蓋、取紙與撥號等操作進度和已完成狀態。報修後顯示已通知公務課，沒有假裝立刻修好。

忙碌時登入工作電腦會遇到一次強制改密碼：前三次選項皆退件，新選項才成功。僅遊戲預設虛構按鈕，不收集真實帳密；離開可稍後續改，成功後本局不重複。

## 完整來電與選項

### 魚刺會診（fish）

類別：門診與一般工作；來源：1F 急診 · 柏宇醫師；需到場互動。

ENT 你好，魚刺會診。成人，意識清楚，目前呼吸平順。吃魚以後覺得喉嚨有刺，想請你評估。

- 補問目前狀況，確認適合上樓後請到 2G → 病人安排到 2G 初診間。小禾會先幫你接待。
- 我到 1F 急診評估 → 好，我們在急診等你。這一趟多走了一些路，也能完成評估。
- 只回「應該沒事」就掛電話 → 還沒有評估，先把目前狀況與經過問完整。

病人：「本來吃得好好的，突然覺得怪怪的。」
小禾：「每位魚刺病人的故事，都是從這一句開始。」

病人已經到診。先把哪些資訊補齊？
- ✓ 確認吃魚經過、症狀與目前狀況，再進行評估 → 病史與現況已記錄，準備進一步評估。
- ↺ 沒看病人，只問他魚好不好吃 → 魚的味道可以晚點聊，先確認現在的狀況。

評估完成，團隊已安排適當處理。接下來？
- ✓ 確認處理後狀況，交代後續注意事項並完成紀錄 → 病人：「下次不吃魚了。」
你心想：這句話的有效期限，通常到下一餐。
- ↺ 事情做完就走，紀錄與交代留到不知道哪一天 → 把這一件收好尾，下一位同事才接得上。

### 會診標題：藍莓（blueberry）

- 直接請病人上 2G 再說 → 這個情境仍有呼吸症狀，先到急診現場共同評估。

- ✓ 補齊嗆咳經過與現況，和團隊確認後續評估安排 → 學長到場，大家確認資訊與分工。

### 病房會診：突然聽不到（sudden）

2026-10-25 依使用者流程改為白天、坐在 2G 初診間才接到的全院病房會診。問發作時間與側別 → 請原病房聯絡聽力室 → 等聽力師另一通完成通知 → 按姓名叫病人 → 比對聽力圖、耳鏡 → 突發性聽損問診與治療說明／正常聽圖與耳垢清理兩種分支 → 回覆原病房。仍占一件，分支不在檢查前揭曉。

完整玩法、個別一週後追蹤及醫療文字範圍見 [HEARING_CONSULT_DESIGN.md](HEARING_CONSULT_DESIGN.md)。

### 房間在轉，我沒有（vertigo）

類別：門診與一般工作；來源：1F 急診 · 柏宇醫師；需到場互動。

- 補齊病況與經過，確認地點後到場評估 → 資訊已補齊，請到 1F 急診。
- 只聽到眩暈，就直接當成耳石問題 → 先確認時序、現況與伴隨症狀，不憑眩暈兩字下結論。

病人：「整間都在轉。」
柏宇：「我們醫院今天沒有開旋轉餐廳。」

現場怎麼開始？
- ✓ 確認症狀時序、神經症狀與目前狀況，和急診分工評估 → 資訊補齊，團隊安排合適評估。
- ↺ 沒問伴隨症狀就先做固定處置 → 不同原因的眩暈要先分辨現況。

病人仍不穩，接下來？

## 診間通知電話的三種回覆

殘冊、換 NG、換氣切共用三個選項：

- 「拋下病房病人，直接下樓」：前往 2G，病房未完成項目保留。
- 「請病人稍等一下，我先查完房再下樓」：仍有未查病床時，回到 patient list 繼續查房；查完自動切回門診工作。清鼻子仍可保留在待辦。若已查完房，直接安排前往診間。
- 「直接掛電話」：不接受、不完成、不計分；關閉回應畫面後稍候，原本的診間電話再次響起，保留同一件工作。

選擇這三種回應本身不額外扣事件分；掛斷後的再來電仍會增加既有的電話煩躁效果。
