# 7F病房：達文西OSA術後第5天吐血

依遊戲製作者提供的臨床流程改寫。保留事件ID `tonsil`，但內容已換成成人OSA病房事件，非急診病童。這一版只包含床邊處置後止住、留病房觀察的情境，不代表所有術後出血都不需手術。

- 主護通報7F23A，術後第5天吐血。先問量與vital signs，再交代含冰水、坐高。本次個案清醒可配合、呼吸平順。
- 可直接到床邊，或先到2G的Fiber位置取器材再回病房。直接到場後若需fiber，可請同事協助送到床邊，玩家留在病人旁。
- 先戴頭燈看口腔。扁桃腺可清楚或不清楚；舌根在本版需fiber確認。隨機兩個出血位置、三種視野組合。
- 找到出血點後先Bosmin紗布止血，再安排Transamin、依現況評估血壓（偏高時處理，未偏高時監測）；無藥物劑量或降壓目標。
- 再看出血與vital signs。本次止住後交代主護持續住院觀察，再出血／狀況改變立即回報評估。完成一次計一件事。
- 原本去16房的分支已移除；`wardOnly`也阻擋舊OR目的地。分類為病房急call，非其他科會診，因此不被刀房會診電話過濾規則擋下。

參考核對：University of Iowa Head and Neck Protocols，術後出血評估、含冰水、局部血管收縮紗布及抗纖溶治療概念。僅供遊戲內容核對，本遊戲的個案分支由製作者決定，非臨床指引。
