# 7F病房：達文西OSA術後第5天吐血

依遊戲製作者提供的臨床流程改寫。保留事件ID `tonsil`，但內容已換成成人OSA病房事件，非急診病童。這一版只包含床邊處置後止住、留病房觀察的情境，不代表所有術後出血都不需手術。

- 主護通報7F23A，術後第5天吐血。先問量與vital signs，再交代含冰水、坐高。本次個案清醒可配合、呼吸平順。
- 可直接到床邊，或先到2G的Fiber位置取器材再回病房。直接到場後若需fiber，可請同事協助送到床邊，玩家留在病人旁。
- 先戴頭燈看口腔。扁桃腺出血用頭燈即可確認，舌根出血需fiber確認。隨機兩個出血位置。
- 找到出血點後，扁桃腺用forceps、舌根用魚刺鉗夾Bosmin紗布壓迫止血；器械選錯時提示重選，再安排Transamin、依現況評估血壓（偏高時處理，未偏高時監測）；無藥物劑量或降壓目標。
- 止血後直接打給二線學長報告，再交代主護持續觀察、再出血回報，事件結束。省去重複確認畫面；完成一次計一件事。
- 原本去16房的分支已移除；`wardOnly`也阻擋舊OR目的地。分類為病房急call，非其他科會診，因此不被刀房會診電話過濾規則擋下。
