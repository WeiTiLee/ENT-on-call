# 刀房來電規則

5F刀房區（含13房、16房與走廊／餐廳）不進醫療會診電話。魚刺、鼻血、NG困難、突然聽不到、各種異物與內容不完整的會診均保留，離開5F後才進來，不取消題目或計分機會。

病房補order、extend、同意書、new pa通知、餐飲電話、門診與主治請託、流動通知刀房工作仍可進來；其他樓層不限制電話類別。電話仍按時間進入，不等待上一件任務完成。

已響過但尚未接的會診，進刀房後暫收，離開後恢復待接；不重複增加脾氣。尚未到達的會診與再次來電保留，延後到可接時才增加脾氣與發出鈴聲。聽力室完成檢查的通知也遵守同一規則。

增加「病房new pa call」到日常隨機池：7F11B林予澄已到病房、準備明日手術，確認姓名、床號與住院目的後回覆。這版只做新住院通知，尚未加入完整收病人流程。每局總題數仍維持個人27／小組12。

製作台新增「刀房來電 · 會診延後」：15:30從13房開始，同時排入四通會診、補order、extend、new pa與16房來電；在5F只能接後四種，離開5F後可接四通保留會診。
