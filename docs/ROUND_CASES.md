# 查房情境

每局從以下五種情境抽出三種，不重複。同一局代碼可重現相同名單；三組使用相同代碼時，晨間工作量一致。

1. SMP術後：查完全部三床，再接病人到7F檢查室清鼻子。
2. Tumor survey：今天安排HNCT、腹部超音波、胃鏡。
3. 今日出院：確認回診時間、出院帶藥與出院病摘。床邊顯示虛構回診安排「下週三上午09:00、蔡主治門診」，並確認出院藥單、用法與天數；完成按鈕明確確認回診與帶藥。
4. 頭頸癌combine術後：主要照顧傷口，線還沒拆、VB還沒拔，再住幾天觀察。
5. Acute epiglottitis：持續住院抗生素治療，明天抽血、再照一次fiber。

沒抽到SMP時，不建立清鼻子待辦、不顯示接病人提示、不會要求護送或清理，也不會因此卡在08:55或擋住交班。清鼻子不列入當局分母，不額外送分：個人局26或27件，小組局11或12件；結算仍依實際任務總分換算70分，狀態占30分。

單項清鼻子試玩仍固定有SMP病人，供製作時檢查護送與清理。查房試玩維持五抽三。以上均為遊戲虛構病人與簡化劇情。
