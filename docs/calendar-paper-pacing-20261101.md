# 7:20 月曆、paper 晨會與白天節奏

## 開場與月曆

正式遊戲從07:20坐在7F護理站開始，不自動開啟晨會視窗。待辦與短提示提醒查看行事曆，玩家點日期上的「今天」才確認當日安排。月曆有上下月、回本月、今天標記與42格日期，今日依台北時間與本局排程固定；不會因重開視窗改題。

晨會類型包括鼻耳次專科、喉次專科、頭頸次專科、paper reading，均07:30在討論室開始。有／無晨會依當局代碼安排。其他日期是遊戲排程示意，並非實際醫院行事曆。

## 晨會

三篇科內虛構paper，每篇三頁報告、兩個主治問題：

1. 近期研究：耳鼻喉科住院醫師脾氣越來越差。
2. 便當一熱，電話就響：一項第一口生存分析。
3. 初診間的筆為何出現在病房？跨樓層遷徙研究。

07:30人在討論室才算準時。提早到可以留在原地等07:30開始。遲到可補報，但紀錄保留並接到主治電話（脾氣+8）；07:45仍未參加或中途離開未回來，列缺席（脾氣+12），不鎖住後續病房工作。提醒各只發一次，未接的遲到電話可被缺席電話取代。報告頁次與問題進度可保留，例行查房也可先處理，會有遲到／缺席後果。

## 時間節奏

白天採彈性工作時間。07:20至07:30放慢到每秒0.1遊戲分鐘；晨會閱讀與白天工作進一步放慢，原有08:30門診電話仍照時間出現，不依任務完成與否才進來。

上午查房／清鼻子未完成時，時鐘保留在08:55；完成後保留移動到初診間的時間，到2G後才越過09:00。下午排定的三台刀房工作未全完成時保留在17:25，完成後正常跨過17:30開始值班。診間與其他白天來電仍可在未完成手術時進入；夜間第一通改為17:45，此後維持原先15–17通的夜間節奏與最大間隔。

工作、旅行、吃東西與脾氣爆炸所花的時間使用同一時間邊界，避免單次操作把時鐘推過目標。耳內注射病人休息使用獨立計時，不會因17:25緩衝而無法完成。此機制只套用正式整局與明確開啟的節奏試玩，單題／自由逛逛保持原本行為。
