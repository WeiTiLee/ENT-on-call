# 醫療情境參考與設計界線

2026-10-23 核對。這些來源用於避免劇情把紅旗症狀當成笑話，並支撐「先評估、接上團隊、交接清楚」的方向。遊戲不重現完整臨床流程、不給劑量、不教侵入性技術；各事件仍是需由科內醫師校閱的娛樂草案。

- [AAO-HNS：Sudden Hearing Loss (Update)](https://www.entnet.org/quality-practice/quality-products/clinical-practice-guidelines/sudden-hearing-loss-update/)：突然聽損事件著重發作時序、及時評估及後續安排，不用未檢查的「耳屎」結論結束事件。
- [NHS：Vertigo](https://www.nhs.uk/conditions/Vertigo/)：眩暈先問伴隨症狀與現況，不把所有眩暈直接當耳石問題；劇情保留急診共同評估與防跌照護。
- [NHS England：Medical device safety](https://www.england.nhs.uk/patient-safety/patient-safety-insight/patient-safety-alerts/enduring-standards/standards-that-remain-valid/medical-device-safety/)：NG 事件不以無咳嗽當成位置正確，要求依院內流程完成位置確認與紀錄後再安排使用。
- [Royal Children's Hospital：Foreign bodies inhaled](https://www.rch.org.au/clinicalguide/guideline_index/Foreign_Bodies_Inhaled/)：藍莓與嬰兒吃魚的幽默只放在標題、同事反應；嗆咳經過與呼吸狀況仍需共同評估，不能只依物品名稱判斷。
- [Children's Health Queensland：Foreign body in the nose](https://www.childrens.health.qld.gov.au/for-health-professionals/queensland-paediatric-emergency-care-qpec/queensland-paediatric-clinical-guidelines/foreign-body-nose)：玩具異物先辨識物品種類，不能直接叫家長盲挖；電池或磁鐵不當成普通塑膠玩具處理。
- [National Tracheostomy Safety Project：Kit checklist and daily checks](https://tracheostomy.org.uk/healthcare-staff/basic-care/kit-checklist-and-daily-checks)：氣切照護保留現況、紀錄、支援與照護交接，沒有教玩家自行換管或套用固定處置。

原有魚刺、鼻出血、術後出血及急氣切的簡化團隊合作框架保留。緊急旗標只控制遊戲來電呈現，不是完整醫療急迫度分級；例如特殊異物仍依劇情現況選擇急診評估。


## 聽障殘冊

計算參考使用者指定之 Hearing Action 試算頁；公式另核對衛生局填表說明，分級依現行附表二甲 b230，未沿用舊資料的門檻。完整來源、日期與遊戲適用範圍見 [聽障殘冊設計](HEARING_GAME.md)。

門診 NG／氣切換管依使用者提供的桌上掛號單、叫名、姓名與管型核對流程細化。NG 聽診與灌水不單獨判定位置正確；新增灌水前核對正式位置確認紀錄的關卡。來源與適用範圍見 [門診換管設計](OUTPATIENT_NG_DESIGN.md)。
