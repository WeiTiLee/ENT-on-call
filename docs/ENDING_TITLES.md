# 六種交班封號

結算頒發一個封號，顯示一行原因，並在下載的值班小卡使用相同名稱。全部名稱由使用者指定。

依序選擇本班特徵：

1. ENT易燃特有種：本班曾脾氣爆炸，或交班脾氣至少80。
2. 公務課之友：完成至少兩項不同地點／項目的修印表機、處理漏水或補衛生紙彩蛋；同一項不重複算。
3. 枕頭試用失敗員：被電話叫醒至少兩次。
4. 電梯里長伯：真正搭電梯至少八次，跨棟步行不算。
5. 冷便當考古學家：本班沒吃值班餐，或交班飽足不超過25。
6. 其餘依交班脾氣：至少50為ENT易燃特有種，低於50為ENT 情緒穩定稀有種。

多項同時符合時依上述順序頒一個；不影響原本任務與狀態成績。新的一班會重置統計。

製作台有「交班封號試看」，六個入口皆直接使用實際結算與分享流程；試看資料不會影響正式成績。
