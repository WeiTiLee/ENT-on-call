# 2G 聽障殘冊事件

2026-10-23。此事件是科內娛樂遊戲，以虛構成人門診資料練習四頻讀值、計算、b230 向度分級與文件交接。它不是補助資格或身心障礙證明核發工具。

## 玩家流程

08:30 診間護理師通知下樓。依當局抽題，可能遇到殘冊、換鼻胃管或換氣切管；不是每局三項全做。殘冊抽到時，玩家到 2G 工作桌登入；第一次忙碌登入仍可能被迫改密碼。

在聽力圖讀取左右耳 500、1000、2000、4000 Hz，各選四個 dB HL 數值。圖形以右耳紅圈、左耳藍叉呈現，符號旁標示數字，亦提供完整文字描述。八項選完才能計算。數值與本題圖表不符時可修正重算。

系統顯示雙耳 PTA、單耳比率及雙耳整體障礙比率，玩家選 b230.0／b230.1／b230.2／b230.3。正確後拿著文件走到診間護理師，互動交出文件才完成事件；只算好或選好答案不會加分。中途關閉保留讀值與計算進度。重新改讀值會清除舊計算、診斷，避免沿用舊結果。

數值輸入錯誤或分級錯誤，按既有事件規則每次扣 2 分、最低 0 分；尚未填滿不扣分。自由逛逛模式可在 2G 工作桌或護理師處練習，不計正式事件分數。

## 計算與基準

- 四頻 PTA = (500 + 1000 + 2000 + 4000 Hz 的閾值) / 4。
- 單耳聽障比率 = (PTA − 25) × 1.5%，以 0～100% 計。
- 雙耳整體障礙比率 = (優耳比率 × 5 + 劣耳比率) / 6。
- 每一步四捨五入至小數一位。先計算單耳再做雙耳加權。
- 成人 b230.1：45.0～70.0%，另納入一耳 PTA ≥90、另一耳 ≥48 dB HL 基準。
- b230.2：70.1～90.0%；b230.3：≥90.1%；其餘 b230.0。

此處是 b230 向度，不是聽損病因，也不是整張證明的綜合等級。目前題庫僅有可測得純音閾值的成人，不出 NR、ABR 或幼兒換算題。純函式保留未滿六歲 22.5% 基準並有年齡邊界測試，但目前遊戲不抽幼兒題。

四組虛構資料涵蓋未達、輕度、中度、重度；依場次及組別可重現。換場可換圖，三組仍保留不同事件組合。正常遊玩不輸入任何真實病人資料，也不向外部試算網站送資料。
