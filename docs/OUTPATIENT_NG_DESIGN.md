# 門診例行換 NG 與氣切：掛號單流程

依使用者說明：護理師會把 NG／氣切管及病人掛號單直接放到診間桌上，接著回主治醫師診間；不留在初診間協助更換。醫師按單上的名字叫病人進來；姓名與管型必須核對。換氣切管後要確認氣流。NG 保留先聽診、再完成後續檢查的節奏。

## 遊戲流程

1. 接到門診通知後，前往 2G 工作桌；這是門診工作，與別科病房「NG 放不進去」會診分開。
2. 桌上有掛號單與密封管子。單上顯示虛構病人姓名、年齡與本次管型，按姓名叫病人進診間。
3. 走到診療椅旁，請病人說出姓名，再與掛號單核對。
4. 從包裝選項中選用正確種類與型號；包含名字近似及管型不同的干擾選項。
5. 更換由玩家操作並以概略流程呈現，不提供深度、角度、劑量或困難換管的操作教學。
6. NG 依序完成聽診評估、院內正式位置確認紀錄、灌水通暢檢查。氣切依序確認氣流與呼吸現況。
7. 整理紀錄，實際走回工作桌放回完成的單子，才結算原事件的 10 分。

名字與管型錯誤可重試，沿用既有扣分規則。中途離開、跨樓、切回病房待辦都保留進度；同一事件不重複給分。兩項仍依抽題出現，每局不保證全做。自由探索可從工作桌選擇練習，練習不計分。

## 物件與資料

掛號單、密封包裝、聽診器、文件與灌水檢查圖示為程式繪製 SVG。工作桌會出現單子與管子，叫人後診療椅上出現病人。管型依使用者提供的實際用語：Teflon 11、Shiley 6、Shiley 8、Bivona 8；NG 14、NG 16。掛號單、包裝、干擾選項與完成紀錄使用同一組名稱。包裝外觀仍為遊戲示意圖。

## 確認方式

聽診聲音與灌水反應不單獨判定 NG 位置正確。遊戲在灌水前，必須核對「依院內流程已完成位置確認」的紀錄。此步為遊戲對既有確認流程的概略呈現，不代替實際檢驗或影像。

來源（2026-10-24 核對）：

- [NHS England：Medical device safety](https://www.england.nhs.uk/patient-safety/patient-safety-insight/patient-safety-alerts/enduring-standards/standards-that-remain-valid/medical-device-safety/)：不以 whoosh test 確認 NG 位置，初始位置確認前不灌入液體；實際採胃液 pH 或影像等院內規範的確認方法。
- [St George’s NHS：Changing a tube](https://www.stgeorges.nhs.uk/gps-and-clinicians/clinical-resources/tracheostomy-guidelines/changing-a-tube/)：更換後確認氣流、病人狀況與紀錄；遊戲不模擬急救或困難換管。

護理師放下物品後離開：換管事件開始即隱藏護理師人物與互動標記，完成換管後也不要求尋找護理師。資料與管子仍留在桌上；殘冊交件有另外的護理師收件情境。
