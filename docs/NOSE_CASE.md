# 急診鼻出血會診

依製作者提供的院內情境設計，科內娛樂用簡化事件。

- 接電話先問是否仍出血、vital signs、能否上樓。穩定者可選1F或2G，不以地點扣分；已不穩定者到1F會合。
- 每次到診重新評估。六個種子分支：小量滲血、Merocel後止血、需加Foley、packing失敗需TAE、到2G後shock、來電時已不穩。
- 2G shock先呼叫支援與處理急變、同步止血，再由團隊陪同轉1F；不能讓病人自行下樓。若同一種子選到1F看，仍可能是大量出血，無須假裝經歷上樓。
- 問出血經過及用藥病史，fiber定位後Bosmin止血綿；依遊戲所示反應選Surgicel或Merocel，仍大量出血可加Foley，持續不止則接TAE評估。
- Merocel止血後交代三天後回診移除；Foley／TAE安排住院。這是製作者指定的本遊戲分支，不代表所有臨床個案只有此處理路徑。
- 支援來電仍可打斷，離開後進度保留，回到同一事件接續；所有分支只計一件事件。

參考核對：AAO-HNS鼻出血指引（https://www.entnet.org/quality-practice/quality-products/clinical-practice-guidelines/nosebleed-epistaxis/），用於核對急變優先、packing移除交代與持續出血轉介的概念；未將本遊戲用藥或院內三日回診規則當作通用指引。
