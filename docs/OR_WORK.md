# 上午排刀與刀房工作站

2026-10-25，按使用者的院內場景逐步完善。所有姓名、病歷號、手術清單和排程均為虛構遊戲資料。

## 上午主治來電

`booking`加入一般工作池，每局仍抽10～15件，沒有強迫每局出現。抽到時放11:30，在13:30進刀房之前。病人、術式、主治與明日上午／下午的交代有三個隨機版本；這份申請屬明日排程，不修改今天13房刀單。

1. 接主治電話，記下便條；未接妥可保留來電。
2. 到2G工作桌登入電腦，原本密碼到期彩蛋可在此發生。
3. 按便條選病人、手術與主治，選指定時段的空位。已有手術的時段停用，資料不符時不能核對通過。
4. 核對、送出排刀申請，再把單子放回桌上，由診間護理師再與病人核對，才完成一次事件。送出與完成分開，重複點擊不重複計分。

填單、核對中途離開會保留資料。自由探索可從初診間工作桌選「主治來電 · 幫忙排刀」練習，不計分。

## 流動旁的電腦

13與16房都放實際可見的工作桌、螢幕、鍵盤、主機與椅子，並有獨立互動點。現在可操作13房NPX biopsy的鼻咽檢體病理order：先在手術台核對病人，再到電腦選病人、order項目與主治，正確才可開單。

開單不是手術完成條件，不取代取樣、止血、標示和流動交接；不重複開單，也不另列抽題。16房先有工作站，其他order內容隨後續事件一起細化，沒有假造可開的處方。

## 到16房找學長

13房刀單全是玩家負責，末欄為主治醫師；沒有「學長負責」或「你協助」的分工欄。耳內注射、NPX biopsy與口腔切片皆可玩，正式值班每局抽其中一台；自由探索可從刀單或手術台選取。

在NPX找病灶、取樣、止血階段可求助。第一次求助先停在原步驟，走出13房、跨走廊進16房，走近學長說明，請他一起回13房。走到16房以前不會自動完成原操作，找刷手拿器械與最後交檢體也不能跳過。學長到場後可協助其餘適用步驟，求助不扣分。也可取消求助，自己繼續。

## 驗證

15組資料與流程檢查通過。排刀檢查150組固定種子，包含病人／術式／主治不符、已滿時段、指定時段、核對退回修改、送出後回覆、只完成一次，以及隨機抽題仍在上午且每局10～15件。NPX求助檢查先到16房、回13房後才能協助，器械與檢體交接仍保留；order檢查資料一致、限13房當台、重複開單與新班重設。

瀏覽器實際完成排刀電話、錯誤病人提示、離開再回來填單、送出與回覆；812×375橫向手機版無水平溢出，可捲動完成操作。13房刀單三欄、流動旁工作站已視覺確認；實際開單可擋錯誤檢體項目、重開顯示已開立且不改手術步驟。NPX觀察階段去16房找學長、回13房後仍在原步驟，學長協助後接續向刷手拿biopsy cup。

## 2026-10-25 流程更正

排刀完成後不用回撥主治。送出申請，再把單子放回工作桌，由診間護理師與病人核對。選項與狀態已改為 `leave-slip`，完成只發出一次。

排刀種類擴充為 NPX biopsy、Oral biopsy、耳內注射、SMP、FESS、tonsillectomy、tumor wide excision、neck dissection、tracheostomy；前3種13房，其餘16房。每份電話便條和申請核對畫面顯示正確房號，空位亦依房號篩選。
