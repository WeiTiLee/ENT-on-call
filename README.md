## 第一批白天事件

07:30 先到護理站按「列印 patient list」，取得三位病人的名單；玩家自行依名單前往，到正確房號與床號旁互動才打勾。三床房使用 A／B／C 編號，例如 7F01A、7F01B、7F01C；雙人房使用 A／B，例如 7F09A、7F09B；單人房維持房號。不同場次有不同名單，同場三組共用名單以維持動線公平。查房清單與床邊對話顯示具體今日計畫：Tumor survey 排 HNCT／腹超／胃鏡、今日出院、SMP 術後清鼻子、10:00 至 2G 初診間給主治看，以及繼續抗生素治療。這些是查房劇情提示；除既有清鼻子任務外，尚未另做排檢查或定時接送子任務。整份名單的所有病床都完成查房後，才能回床邊接 SMP 術後病人，帶到中央檢查室清鼻子；只完成 SMP 那床仍不能提早接走。護送中若要離開病房，可先請病人回床邊等候。在檢查室按住三個遮擋區清理（鍵盤 Tab／Enter 亦可），再確認紀錄、安排送回病房。

08:30 由診間護理師通知樓下門診有聽障殘冊、換氣切管或換鼻胃管，三組各抽不同一項；不是病房會診，不要求先完成查房。13:30由13房流動通知耳內注射、NPX biopsy或口腔切片之一已準備好，每局隨機一台。病房 NG 放不進去的會診與資訊不全來電，必須先回 2G 初診間工作桌，坐下後才會收到病房電話。接受來電、切換待辦與上下樓會保留查房、檢查室清理進度。接下診間通知後，主流程轉入 2G；完成第一件門診工作就接續早上的初診間事件，不強制先返回病房。未完成查房與清鼻子留在待辦，可自行切回，交班前需收尾。第一通之前的遊戲時間加速；對話、名單、暫停與小遊戲時停止計時。抽到的一般門診／會診安排於上午，下午由流動通知進刀房；夜間的臨床細節可繼續逐一調整。

## 本機試玩

需要 Node.js 18 以上；無須安裝套件。

```sh
npm start
```

開啟 http://127.0.0.1:8790/ 。預設伺服器提供 `dist/`；用 `node tools/serve.mjs --root .` 可查看保留的原始範本。

```sh
npm test
```

檢查原始範本資料，以及 ENT 版本的樓層動線、劇情進度、會診選項、來源標示。

## 操作

- WASD／方向鍵移動，Shift 快走；也可點擊地面或場景標記。
- E 與附近位置互動；C 接電話。
- 任務卡「帶我走近」會走到下一個互動點，再按 E；跨棟和電梯仍需玩家操作。
- 手術小遊戲：按住清除三個遮擋區，再對準移動目標按住，完成三次穩定操作。可重試或請學長支援。
- 手機請橫向遊玩，提供觸控方向鍵；暫停和操作說明在右上方。

## 聽障殘冊小遊戲

在 2G 工作桌看虛構聽力圖，選取左右耳 500／1000／2000／4000 Hz 八個閾值，計算 PTA 及雙耳障礙比率，選擇 b230 聽覺功能分級，再走向診間護理師交出文件才完成。中途離開保留進度。依場次與組別換圖；殘冊、NG、氣切仍依抽題出現。自由逛逛也能在初診間練習。計算式、現行分級來源與題庫界線見 [聽障殘冊設計](docs/HEARING_GAME.md)。

## 門診掛號單與換管

早上抽到門診 NG／氣切事件時，先到 2G 工作桌讀掛號單、依姓名叫人，再走到診療椅核對姓名、選正確包裝管型。護理師放下單子與管子後回主治醫師診間，由玩家完成更換。NG 依序為聽診、核對正式位置確認紀錄、灌水通暢檢查；氣切為氣流與呼吸現況。紀錄完成後走回工作桌放回單子才計分。中斷與跨樓保留進度；自由探索工作桌可選練習。管型依使用者提供的 Teflon 11、Shiley 6、Shiley 8、Bivona 8、NG 14／16，包裝為遊戲示意圖；詳見 [事件設計](docs/OUTPATIENT_NG_DESIGN.md)。

診間通知電話可選直接下樓、請病人稍等先查完房、直接掛斷。先查房會保留門診工作並在查房後切回；掛斷後同一通通知會再打來，不會直接完成或跳過事件。

### 刀房電腦、學長與上午排刀

刀單三欄為病人、手術、主治醫師；13房的三台都由玩家負責，目前可玩的手術仍為NPX biopsy。13／16房流動旁均有住院醫師電腦，13房核對病人後可開立本台的鼻咽檢體病理order；錯誤資料會阻擋、重複開單不重複登記，這個操作不跳過手術步驟，也不另加抽題件數。16房其他order內容待後續事件完善。

NPX看病灶、取樣或止血需要學長時，先保留操作、到對面16房實際找學長，再回13房接續。請學長不扣分；拿器械與檢體交接仍須自己完成。

「主治來電：幫我排一台刀」加入隨機一般事件池，抽到時在11:30、下午刀房前出現。按電話便條的病人、術式、主治與明日時段，在2G工作桌電腦選空位，核對、送出排刀申請並回覆主治；自由探索也可從工作桌練習。初診間與刀房共用原本密碼到期彩蛋。資料皆為虛構遊戲資料，不連接真實院內系統。
